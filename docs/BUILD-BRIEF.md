# Build-agent handoff

Mission: evolve CORE/SIGNAL into the fastest publicly sourced strategic learning tool for the server CPU landscape, without turning it into an uncited market forecast or a documentation-heavy shell.

## Startup steps

1. Read `README.md`, `docs/COMPLIANCE.md`, `docs/EVIDENCE-STANDARDS.md`, `docs/STRATEGIC-FRAMEWORK.md`, `docs/RESEARCH-ROADMAP.md`.
2. Run `npm run check` and `npm start`; inspect desktop and 390px mobile widths.
3. Do not merge changes that increase unsupported numeric precision or disclose restricted consultation context.
4. Identify the single next most useful visual interaction, define success condition, add evidence, implement and test.
5. Prefer an incremental addition to existing pure JS and CSS. Adopt a framework only with a concrete justification around increased complexity, scale or developer productivity.
